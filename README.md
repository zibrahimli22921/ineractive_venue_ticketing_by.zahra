# Interactive Venue Ticketing System

An interactive, responsive venue seating map application built with HTML, CSS, and Vanilla JavaScript.

## Features
- **Interactive Seating Map:** Inspect seat status, row information, and pricing categories.
- **Cart & Selection Management:** Add/remove seats dynamically with duplicate selection prevention.
- **Map Viewport Controls:** Zoom in/out and pan navigation for large venue layouts.
- **Data Persistence:** Integrated `localStorage` to save and restore selected tickets across page reloads.
